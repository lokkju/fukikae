fukikae studio

The studio page is pending: its design waits on the operator's pick (D47). The server, the JSON API and audio serving are running; this placeholder lists the API.

Every request needs the token printed at start-up. Opening the start-up URL once (/?t=<token>) sets a cookie that authorizes reads in this browser; every POST also needs the X-Fukikae-Token header, and its body is JSON (1 MB at most).

Routes

  • GET /: this page.
  • GET /static/<file>: the page's files, from the package only.
  • GET /api/season: the season index (SeasonDoc), rebuilt when its inputs changed.
  • GET /api/characters/<id>: one character's entry (CharacterEntry).
  • GET /audio/<sha256>.wav: a clip the index refers to (a sample's clip).
  • POST /api/decisions/preview: what an identity decision would rerun, and whether its digest is stale; writes nothing.
  • POST /api/decisions: apply an identity decision (every op but accept); returns the rebuilt character. 409 when stale or unfinished, 422 when refused or carrying no digest, 423 while a run or another writer holds the studio lock.
