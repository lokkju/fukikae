fukikae studio

The studio page is pending: its design waits on the operator's pick (D47). The server, the JSON API and audio serving are running; this placeholder lists the API.

The token printed at start-up rides in this page's address after #t=, a part of the URL a browser never sends to a server. /static/token.js moves it into this tab's session storage and clears it from the address bar; every /api and /audio request then sends it as the X-Fukikae-Token header, and audio is fetched with that header and played from a blob URL. There is no cookie and no token in a query string. This page and /static/ need no token and hold no data. POST bodies are JSON (1 MB at most).

Routes

  • GET /: this page (no token needed).
  • GET /static/<file>: the page's files, from the package only (no token needed).
  • GET /api/season: the season index (SeasonDoc), rebuilt when its inputs changed.
  • GET /api/characters/<id>: one character's entry (CharacterEntry).
  • GET /audio/<sha256>.wav: a clip the index refers to (a sample's clip).
  • POST /api/decisions/preview: a dry run of an identity decision: what it would rerun, whether its digest is stale or missing, and the decision with its digest filled in (decision), to post as previewed; writes nothing.
  • POST /api/decisions: apply an identity decision (every op but accept); returns the rebuilt character. 409 when stale or unfinished, 422 when refused or carrying no digest, 423 while a run or another writer holds the studio lock.
